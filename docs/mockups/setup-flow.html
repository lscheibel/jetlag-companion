Two doors, then one thing at a time

Opening a game is the first thing anyone does with this app, and the only part a host does under no time pressure — which is exactly why it should not be one long form. Every screen here asks for one decision, arrives with a sensible answer already in place, and can always be backed out of. Nothing is final: all of it stays editable while people are still turning up.

Create is the loud one

Most people arrive by somebody’s link or QR code and never see this screen at all. Of the ones who do, nearly all are the person opening the game — so creating is the full-width action with the shadow under it, and typing a code is the quieter door beside it.

The quiet door

A code, then a name — in that order

Nobody types their name into a game that turns out not to exist. The code resolves first and shows what it found; only then is there any point asking who you are.

Shape of the flow

Back always means one step up

Setting the area is a whole task in itself, with three different ways in — which raises the question of what the back arrow means once you are inside one of them. The answer that keeps the flow honest: those three are a detour that hands its result back, not a place the wizard sends you and then forgets about you.

Solid arrows move forward. Dashed yellow is the back control, which never leaves the flow: it goes up exactly one level, and from the first step it returns to the start screen. The alternative — handing off to a full-screen area editor with a life of its own — was rejected because the wizard’s progress would have to survive a round trip it does not control, and back would mean two different things on neighbouring screens.
Create a game

Four decisions, three of them already made

Name yourself, say where, say what counts as transit, say how long you have got. Each one opens with a working answer in place, so a host who wants to start in twenty seconds can press straight through, and a host who wants to spend an hour building a map still can.

The detour

One editor, every tool, any number of pieces

The three ways in are seeds, not lanes. However you started, the editor has all of it: add a district to an imported map, draw a circle around a station, cut the airfield back out. An area is a list of pieces added and taken away in order — the same shape the seekers’s search area has later, for the same reason: anything built from an editable list can be undone one step at a time.
