The map knows more than it says

Both roles get the same map and a different truth on top of it. Hiders watch every seeker team move; a seeker team sees only its own dots, and sees everyone else honestly labelled as present-but-hidden. Staleness is drawn, not hidden. The toolkit puts the things people currently open Google Maps for inside the app.

Two roles, one canvas

Asymmetry you can see at a glance

The valid hiding area is drawn as what it is — the union of enabled station radii, dashed because it constrains hiding spots and not travel. Everything above it is position data, and position data is the only thing the visibility rules ever touch.

Visibility

Only position is ever hidden

Everyone always sees who is in the game, which team they are on and whether they are online. The matrix below covers one thing and one thing only: whose dot appears on whose map. It is a server-side filter that keeps the game fun, not a security boundary — and nobody spends a day defending it against a player with dev tools open.

Toolkit

The measurements people currently leave the app for

Distance along a path, a radius around a point, shared pins, a suspected search zone. Both roles get the same geometry, so a hider and a seeker measuring the same line read the same number.

Map controls
48 px round targets, right edge, 9 px apart. Recenter, rotate-to-north, 3D tilt, layers.
Motion
Markers drop in staggered by 120 ms; own position keeps a 3.2 s accuracy pulse and a slow heading sweep. Nothing else moves on its own.
Staleness
Live → 55% opacity at 3 min → 33% and greyed past 10 min, each with the words next to it.
Honesty
No GPS, no battery API, no signal: the screen says which, and every tool still works from a tapped point.
